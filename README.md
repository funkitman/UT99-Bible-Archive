# UT99 Bible Archive

An archival project for the community-created **UT BIBLE**, a competitive *Unreal Tournament (1999)* duel strategy guide authored by **ocr*flocutus / Florian Blümm**.

All original UT BIBLE prose, concepts, images and other original materials are credited to **ocr*flocutus (Florian Blümm)** and their respective creators. ## Preservation status

**Work in progress.** This repository currently documents provenance and the restoration plan. It does **not** yet contain a verified complete copy of the original website. Missing pages, images, and demos must not be presented as recovered.

## Restoration workflow

1. Inventory pages and assets from the surviving mirror.
2. Compare with archived captures of the original domain.
3. Save available source files unchanged, with their source URLs and retrieval dates.
4. Track missing/broken links and any reconstructed elements separately.
5. Verify internal links and downloadable demos; document failures.
6. Preserve original credit and copyright notices on every archived page.

A possible local mirror command (review site terms and avoid aggressive requests):

```bash
wget --mirror --convert-links --adjust-extension --page-requisites --no-parent --wait=1 https://digdilem.org/ut-bible/
```
